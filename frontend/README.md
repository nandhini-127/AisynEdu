# AisynEdu — Frontend Application

This directory contains the production-ready React + TypeScript frontend for **AisynEdu**.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

## Features
- **Modern SaaS Design**: Clean layouts, consistent spacing, Inter typography, and light/dark theme toggle.
- **Agentic AI Tutor**: Unified chat with Markdown and KaTeX math formatting ($...$), document citations, and multimodal diagram support.
- **RAG Document Library**: Upload, inspect, filter, and delete course materials with real-time status and metadata.
- **Interactive Quiz Center**: Generate MCQs with instant scoring, feedback, explanations, and celebration animations.
- **Study Notes**: Generate structured revision notes and export to `.md` files.
- **Learning Analytics**: Visual weekly telemetry charts and subject focus breakdown.
- **Secure Authentication**: Registration with client-side password strength validation, JWT access & refresh tokens, and route protection.

For comprehensive architectural specifications, refer to [docs/FRONTEND_SETUP.md](../docs/FRONTEND_SETUP.md).
